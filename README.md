# UDA Contractor Dashboard

**NHS dental performance analytics dashboard built in Excel**

> A comprehensive Excel dashboard analyzing 6,977 contractor records across 42 NHS commissioners with 24.5M+ patients tracked and 32 performance indicators.

---

## 📊 Dashboard Highlights

| Metric | Value |
|--------|-------|
| **Contractor Records** | 6,977 |
| **Data Fields** | 32 |
| **NHS Commissioners** | 42+ |
| **Patients Analyzed** | 24.5M+ |
| **Total Revenue** | £3.07B |
| **UDA Units Delivered** | 5.97M |

---

## 🎯 Key Features

✅ **Executive Dashboard** - KPI summary sheet with key metrics  
✅ **Raw Data Analysis** - 6,977 rows with complete transaction data  
✅ **Multi-level Summaries** - Regional breakdown tables  
✅ **Performance Tracking** - 4-tier performance categorization  
✅ **Financial Metrics** - Cost-per-UDA and revenue analysis  
✅ **Patient Access** - Child (12M) and adult (24M) tracking  
✅ **Interactive Pivot Tables** - Ready for custom analysis

## 🚀 How to Use This Dashboard

1. **Open the Excel file** with Excel 2016 or later
2. **Review the Dashboard sheet** for executive overview
3. **Explore raw data** in the main sheet
4. **Create pivot tables** for custom analysis
5. **Use summary tables** for quick regional insights

### Quick Tips
- Filter by Performance Category to segment contractors
- Sort by UDA_DELIVERY_RATE_PCT for ranking
- Use COMMISSIONER_SHORT for regional grouping
- Analyze Cost_Per_UDA for efficiency insights
